# LULL

一个伪装成智能家居营销页的滚动叙事网站。前 60% 是一份正常、干净、甚至有点好看的产品页；往下滚，它会逐渐不对劲，最后变成别的东西。

纯静态：`index.html` + `styles.css` + `script.js`，无构建步骤、无依赖。

## 本地打开

直接双击 `index.html` 即可。若想更接近线上环境：

```bash
npx serve .
```

## 结构

滚动进度被压缩成一个 `0 → 1` 的变量 `--q`，全站的视觉变化都挂在它上面：

| 区段 | 发生了什么 |
| --- | --- |
| Hero | 一颗安静的产品球体，光在它表面缓慢移动 |
| Presence | 雷达扫描房间——它在"感知"，但不解释感知什么 |
| Spaces | 每个房间的卡片，文案开始有第二层意思 |
| Voices | 用户评价，逐渐不像人写的 |
| Booking | 预约安装。背景在自己变暗 |
| Descent | 长滚动下沉，一个轮廓在黑暗里逐渐靠近。永不失焦 |
| Breach | 那颗球睁开一只眼 |
| Ending | 晚安 |

## 一点说明

页面里没有任何图片资源——所有形状、噪点、光晕都是 CSS 渐变和 canvas。声音由 Web Audio API 实时合成，没有音频文件。

右上角可开关声音。建议开着滚一遍。
